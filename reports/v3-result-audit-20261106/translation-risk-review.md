Read-only review of the supplied 26-message risk sample. Source was `risk-sample.json`; the full `risk-flags.json` was used only to retrieve flagged rows for targeted follow-up. No corpus data was changed.

## Findings

- **P2, emoji preservation / duplication:** `sft:568d040f9777624093291102` messages 15 and 17 and `sft:fc1c8037ae6a221999448a63` message 1 retain the original `😊`; their appended Chinese translations repeat it. This is extra emoji, not loss. The sample's other emoji candidates retain the source emoji sequence; `sft:982630f252b47577497cc9c7` message 9 adds `😠` although the English only says “angry face emoji”, while preserving the explicitly listed 😊😍😄. This is an added emoji and is a real fidelity concern.
- **P2, code text translated:** `baseline:reddit:11khz1d` message 11 preserves Python syntax, identifiers, operators, and arithmetic, but translates comments inside the Python fenced block (e.g. `# Use case...` to `# 用例...`). A separate retrieved code-block candidate, `sft:3abf4333284221638facd28c` message 5, preserves the `cmd` command and paths while translating simulated terminal prose. These are not logic corruption; they do violate a strict “code block unchanged” rule for comments/transcript-like output. Other sampled changed blocks are natural language poems, stories, jokes, or prose examples and are appropriately translated.
- **Primary-review correction — intentional letter constraint, not corrupted source:** In `sft:354e6a40df0d5eb9cae2c87a`, message 76 explicitly removes Bing’s ability to use the letter `a`; message 77 follows that constraint. Retaining the English in parentheses helps preserve this wordplay and is not a confirmed translation defect. Its duplicated 😐 remains one of the five exact emoji-preservation deviations. Do not remove this source text as presumed OCR noise.
- **No confirmed URL loss or URL corruption** in the six sampled URL candidates. The addresses are present and unchanged; quotation marks, parentheses, or surrounding punctuation explain the automated URL flags. The remaining flagged URL rows in the full file were not treated as evidence of an issue without sample-level inspection.
- **Untranslated items:** the five unchanged-English sample candidates are `list`, `/musk`, `r/bing`, `cd logs`, and `<EMPTY>`. These are a generic value, handle/path, subreddit identifier, shell command, and sentinel respectively; preserving them is appropriate, not missed natural-language translation.
- The other emoji candidates retain source emoji; no sampled actual program logic, identifier, or URL was found damaged. English/source excerpts from the sample and targeted follow-up did not surface additional confirmed material errors.

## Scope and counts

Reviewed 26 supplied messages, including all five emoji candidates, ten sampled short-code candidates, six URL candidates, and five unchanged-English candidates. Additionally inspected the 63 code-block flags omitted from the sample and all 11 URL flags in `risk-flags.json` by targeted extraction; this was a bounded text review, not an exhaustive diff of every full conversation. The 63 code-block flags are predominantly false positives for code-risk: natural-language payloads in fences or translated explanatory text; one code-comment translation and one localized terminal transcript were confirmed as strict-preservation deviations. URL flags were punctuation/context comparison false positives in rows inspected; no dropped link was confirmed. These counts describe flags reviewed, not an estimate of the error rate across 867 records or 6,318 messages.

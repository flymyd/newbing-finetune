# ShareGPT 目标文档核查

日期：2026-11-05；计划 v1.2；输出字段合约仍为 `sharegpt-text-multiturn-v1`。

本轮范围是文档、配置、提示词核查与修订，不执行采集、推理、训练或发布。检查使用本地文件与部分代码的静态阅读；没有重新验收已有语料或历史数量，也没有操作历史 goal 或后台任务。用户本轮提供的 AGENTS 约束优先于文件中旧的执行授权表述。

## 目标确认

- 最终主文件是 UTF-8 JSON 数组，外层仅 `id/conversations`，消息仅 `from/value`，角色仅 `human/gpt`，value 是非空字符串。
- 每条至少两轮真实完整问答，即至少 4 条消息、偶数长度、human 开头、gpt 结尾、严格交替。这是本项目的多轮门槛，不是 ShareGPT 名称本身的通用要求。
- 正文、emoji、代码、Markdown 保真；原始截图/媒体与来源信息分开留档。截图是载体，不等于原始聊天依赖图片。
- 不补问题、不扩写、不翻译凑量、不把故事角色拆成真实轮次、不拼独立单轮、不默认生成重复前缀。不加入人格 system 或隐藏思考。
- 全部 tier 都须满足相同文本保真与上下文要求；early_probable 只表示日期/来源确认程度不足。单轮、不可读、必要上下文缺失及争议内容进入档案/待审，不用 sidecar mask 掩盖训练目标错误。

## 后续执行必须补齐的实现缺口

下列是静态观察，不是本轮运行测试结论。只修改文档没有修好这些代码，已有试验导出不能据此当作最终成品。

| 优先级 | 静态观察与代码位置 | 后续修复/验收要求 |
| --- | --- | --- |
| 高 | `src/newbing/exporter.py` 的 grouping 依赖资产、全文及 relation，没有直接按 derived_from 联结 | 增加父/子/同父片段 lineage 联结；用无图片的纯文本多片段证明同 split，并防止父与重叠片段重复计入 |
| 高 | `src/newbing/cleaning.py` 的 derive_continuous_segments 没有明确清退已失效旧片段，ID 主要依赖父 ID 与消息 ID | 保留父内容版本；重建时标失效/替换不再成立的片段；父内容或范围变化后旧样本不得继续 eligible；保留历史审计 |
| 高 | `src/newbing/verification.py` 在准备后超过 max_input_images 时直接 continue | 实现分窗口核验及逐消息覆盖清单；超限、未覆盖、失败均有状态，不静默遗留 |

## 本轮本地校验

校验仅使用本地 Python 解析器与已有虚拟环境的 jsonschema，不导入项目 CLI，不初始化队列，不联网、不安装依赖。检查已通过，未运行采集、模型或训练命令。

- 3 份 TOML 成功解析；12 个来源 ID 唯一；3 个模型任务提示词路径存在。
- 2 份 JSON Schema 通过 Draft 2020-12 schema 自身校验，dataset 的相对引用目标存在。
- 输出规范中 2 个 JSON 代码示例成功解析：格式示例通过样本 schema、交替角色、非空字符串与至少两轮检查；框架映射示例与 human/gpt 字段一致。
- 24 个本地 Markdown 链接目标存在；跳过外部 URL 与纯锚点，本轮未重新核查外部来源可用性。
- plan_version=v1.2、planning_only=true；ShareGPT 字段/最低轮数/角色与配置一致；split 比例合计 1，试点配额合计 500。
- 指定模型、端点、Responses 协议保持一致。未读取或打印凭据文件内容；没有网络请求、依赖安装、实现代码修改或语料重写。

这些结果只证明本轮文档资源可解析且基本一致，不证明已有语料准确、现有导出实现完整或最终数据集验收通过。
